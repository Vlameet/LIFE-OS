# LIFE OS

Кроссплатформенное приложение на Flutter для Android и Windows.

## Возможности стартовой версии
- Обзор дня
- Задачи и привычки
- Цели и прогресс
- Финансовые записи
- Заметки
- Локальное сохранение данных на устройстве

## Сборка
GitHub Actions автоматически собирает Android APK и Windows-версию при push в `main`. Сборки можно также запускать вручную во вкладке **Actions**.

Данные пока хранятся локально на каждом устройстве. Облачной синхронизации между Android и ПК пока нет.
